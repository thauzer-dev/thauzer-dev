## Projetos em destaque

### Dados e soluções de negócio

- **[Lab - Patologia](https://github.com/thauzer-dev/Lab---Patologia):** pipeline analítico para operações laboratoriais, com qualidade de dados, indicadores de SLA e Random Forest para estimar o risco de atraso por requisição.
- **[System of Price](https://github.com/thauzer-dev/System-of-Price):** sistema de apoio à precificação de peças, considerando custos, impostos e margens por loja, com registro de ajustes.
- **[Excel — Forms](https://github.com/thauzer-dev/Excel---Forms):** script em desenvolvimento para facilitar a transição de profissionais que trabalham com dados no Excel.
- **Análise de acidentes no Ceará:** projeto acadêmico de Estatística Aplicada com dados da PRF e visualização de resultados.

### Automação de processos

- **[RPA — Archives](https://github.com/thauzer-dev/RPA---Archives):** automação em Python de rotinas com arquivos, apoiando a preparação e a atualização de informações.
- **[RPA — Fonts](https://github.com/thauzer-dev/RPA---FONTS):** automação em Python voltada a rotinas com fontes de dados e arquivos para apoiar o tratamento operacional das informações.

Os dois RPAs contam com informações detalhadas sobre a operação e indicadores de acompanhamento dos processos, ampliando a visibilidade sobre a execução das rotinas.

### Aplicações e interfaces
